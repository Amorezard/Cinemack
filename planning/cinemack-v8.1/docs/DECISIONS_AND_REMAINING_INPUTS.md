# Locked decisions versus decisions requiring real project inspection

## Approved by user

- P0: structured RAG/search/caching and embeddings/chunking; personalized recommendation service; detailed box-office prediction model and factor/correlation research with gross ranges and uncertainty.
- Box-office factors: release timing, directors, actors, writers/creators, producers, genre/type and related market variables. Explain correlations without inferring causation.
- P1: Pick Tonight one reason/title, Calendar, meaningful application of screenshot's 20 UX/animation principles, concurrent users and safe Ollama tools.
- P2: multilingual support, movie ticket deals including Monday/Tuesday promotions, bundles, subscriptions, streaming offers and alerts.
- General: preserve working site, audit first, independent acceptance criteria, safe testing, commits and rollback.

## Design choices for Claude to resolve with evidence

- Existing DB schemas and best adapter for canonical film ID and source provenance.
- Source-specific index/chunk sizes, embedding model, reranker, prompt version and TTLs based on measured quality/latency.
- Recommender feature store and model class based on actual positive/negative feedback volume.
- Gross forecasting targets/horizon support, missing source treatment, calibration approach and model selection; no guarantee all outputs can be estimated reliably.
- Existing CSS tokens and front-end component architecture; do not rewrite previously approved page design.
- Ollama parallelism, queue implementation, possible vLLM benchmark only with compelling evidence.
- Current legal rights to article content, streaming availability and theater-price data.
- Scope of initial language translations based on available resources.

## Requires explicit authorization before execution

- Production deployment, service restarts or DNS/HTTPS changes to shared hosting.
- One-shot sealed evaluation consumption.
- Destructive migrations, database/index replacements, data deletions.
- Paid API licenses/scraping, affiliate or commercial changes.
- Sending emails/push alerts to real users.

## Do not confuse these

Approved roadmap ≠ permission to buy services or alter production. Bundled schemas ≠ live app schema. Research baseline from README ≠ independently reproduced result. UX reference video screenshot ≠ current Cinemack page screenshot. No invented availability, gross numbers, deals or passing tests.
