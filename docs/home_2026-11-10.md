# Home redesign and genre filtering fix (Tue 10 Nov 2026, round 17)

Brief: "Homepage redesign & genre filtering fix" plus one reference image. Ships with the five-page redesign in
round 17 at `/v8`. Nothing in the answer pipeline, retrieval or evaluation changed.

## 1. Where Home's films come from (before)
| Row | Source | Ranking |
|---|---|---|
| Hero carousel | TMDB now-playing list (US) | list order, new releases first |
| In theatres now | same list, new releases | list order |
| Because you liked X | MovieLens neighbours of liked films | neighbour rank |
| Your watchlist | saved films | newest first |
| Coming soon | TMDB upcoming list (US), date today or later | **TMDB list order, not by date** |
| What everyone's watching | films out in the last 120 days, 20+ votes | popularity, **top 80 taken before the genre filter** |
| Back in theatres | re-releases on the now-playing list | list order |
| Top-rated X / Recent X | only when a genre was chosen; 800+ / 150+ votes | **raw rating, then re-sorted by match count; no tie-break** |

## 2. Root causes of the multi-genre problems (reproduced on a controlled catalogue)
Reproduction (old code, fixture data): with every chip selected, In Theaters lost 1 of 12 films and changed order,
Popular lost 2 of 12, Coming soon lost 5 of 15, and two extra genre rows appeared.

1. **Silent truncation to 6 genres.** `/api/v8/home` and `discovery.home()` kept `genres[:6]`; `user_prefs.clean_chat`
   did the same for the chat. Choosing all 13 chips sent Action, Animation, Comedy, Crime, Documentary and Drama only,
   so Thriller, Sci-Fi, Romance, Mystery, Horror, Fantasy and Family films vanished, and the chat ignored them too.
2. **Two genre lists.** The server knows 18 TMDB genres (`user_prefs.GENRES`); the page offered 13 chips. "Every chip"
   still excluded Adventure, History, Music, War and Western films and films with no genre data.
3. **Re-ranking by match count.** `_keep_genres` sorted every row by how many selected genres a film had, replacing
   each row's own order; the more genres chosen, the more the rows were shuffled.
4. **Filtering after the cut.** Popular took its top 80 and then filtered, so a genre could come back short or empty
   while matching films existed further down.
5. **No deterministic order.** No secondary sort on equal ratings or popularity; `Coming soon` kept TMDB's list
   order instead of dates.
6. **Genre-only rows on top of filtered rows.** "Top-rated X" and "Recent X" appeared only with a filter, so the page
   changed shape when a chip was clicked and duplicated films from the other rows.
Checked and not a cause: random sampling (none), client-side re-sorting (none), cached responses (`no-store`), races
(the page already dropped stale answers; it now also aborts them and debounces 180 ms), duplicate ids (each row is a
single ordered list).

## 3. Rules now (server: `discovery.genre_filter`, `match_genres`, `home`)
- No genre: every row in its normal order.
- Match Any (default): a film is eligible if it has at least one selected genre.
- Match All: only films with every selected genre (needs two or more; with one genre it is Any).
- Every genre selected: no restriction, the same rows in the same order as no genre (also with Match All).
- One list of 18 genres for the server, the chips (sent as `genre_options`) and settings. Unknown names ignored, never cut.
- The filter runs on each row's whole candidate list before it is cut to 20, never reorders a row, and never adds
  films from outside the row. An empty row says so and offers Clear filters (and Match any when on All).
- Excluded genres, services and age limits are separate settings and are not touched by these chips.
- The chat receives the same genres (Match Any); "every genre" is sent as no genre.

| Row | Eligible | Ranking (ties: TMDB id) |
|---|---|---|
| Hero (unfiltered) | new films then re-releases on TMDB now-playing (US) | list order |
| In Theaters Now | new releases on now-playing | TMDB list order |
| Recommended for You | MovieLens neighbours of films the person liked (only with real likes; otherwise an honest prompt) | neighbour rank |
| Top Rated | 500+ TMDB votes | weighted rating WR = v/(v+1500)·R + 1500/(v+1500)·C (C = mean of 500+ vote films) |
| Trending Now | released in the last 120 days, 20+ votes, not already in the In Theaters row | TMDB popularity |
| Opening Soon | TMDB upcoming (US) with a date today or later | confirmed date, earliest first; label In theaters / Streaming / US release |
| Your List | saved films; with a filter it says "3 of your 8 saved films match"; 1-2 films use a compact row | newest saved first |
| Back on the Big Screen | re-releases on now-playing | list order |

## 4. Page changes
Content width up to 1360 px. Cinematic hero: backdrop of the featured film (two layers cross-fade, images warmed
ahead), title, year, rating, genres, runtime, overview, Details / Watchlist / Showtimes, with "What are we watching
tonight?", the Ask box and Pick Tonight above it. 5-second autoplay with a pause button (WCAG 2.2.2), arrows, dots,
arrow keys, swipe; pauses on hover, focus, touch, open dialogs and hidden tabs; never moves with reduced motion. Only
the hero moves on its own. Explore by Genre panel: nine chips plus More, strong selected state, Match Any / All
(disabled under two genres), Clear all, and a one-line summary. Rows update in place (old rows fade while loading).
Posters: missing artwork gets a styled card with a film icon, the title and the year; a slow image shimmers then fades
in; a failed image (404) is replaced by the same card.
